# AnalysisReasoningNode - "The System's Mouth, Not Its Brain"

## Overview

AnalysisReasoningNode is the critical AI governance boundary in the audit pipeline. It serves as the **exclusive entry point** for AI-generated explanations into the audit process, ensuring that AI serves only as an explanatory assistant, never as a decision-maker.

**Core Philosophy**: "AnalysisReasoningNode is the system's mouth, not its brain. It can explain, but it can never decide."

## Position in Audit Pipeline

```
Data → Metrics/Rules → ResultGenerationNode → [AnalysisReasoningNode] → HumanReviewNode → ExportReportNode
```

- **Before**: Structured audit results from ResultGenerationNode
- **After**: Human confirmation required for all AI explanations
- **Purpose**: Generate immutable reasoning snapshots for human review

## Governance Principles

### 1. **Input Boundary Enforcement** (Critical)

AnalysisReasoningNode **MUST ONLY** accept:
- ✅ RuleCalculationNode rule_hits (structured trigger data)
- ✅ AuditResult references (structured audit findings)
- ✅ HumanReviewNode status (optional context)

**STRICTLY FORBIDDEN**:
- ❌ Raw DataFrames or datasets
- ❌ File paths or direct file access
- ❌ Unstructured data or free-form inputs

**Governance Implementation**:
```python
def _validate_inputs_governance(self, rule_hits, audit_result_ref, human_review_states, metric_snapshot):
    # BLOCK raw DataFrames, file paths, and suspicious data patterns
    # RAISE ValueError on governance violations
```

### 2. **Immutable Reasoning Snapshots**

All outputs are persisted as **immutable audit evidence**:
- Atomic write to `{STORAGE_PATH}/analysis/{workflow}/{run}/{analysis_id}.json`
- SHA256 integrity verification
- Timestamp and provenance metadata
- Cannot be modified after creation

### 3. **Mandatory AI Governance Compliance**

**Model Information** (always included):
```json
{
  "model_name": "analysis-reasoning-v1.0",
  "model_version": "1.0.0",
  "capabilities": ["explanation", "correlation-analysis", "hypothesis-generation"],
  "limitations": ["no-decision-making", "requires-human-confirmation", "no-raw-data-access"],
  "governance_level": "L2-audit-assistant"
}
```

**Disclaimer** (always included):
```json
{
  "content_type": "ai_generated_explanation",
  "governance_status": "requires_human_confirmation",
  "decision_authority": "none",
  "disclaimer_text": "This analysis is generated by an AI system and serves only as explanatory assistance..."

```

## Audit Chain Integration

AnalysisReasoningNode establishes **evidence chain links**:

1. **Persists immutable snapshot** to storage
2. **Updates AuditResult metadata** with `analysis_refs`
3. **Links to evidence chain** via `evidence_link_type: "explanation_of_findings"`

This creates traceable connections between AI explanations and audit findings.

## Governance Flags

Critical compliance indicators in output metadata:

| Flag | Purpose | Required Value |
|------|---------|----------------|
| `input_boundary_enforced` | Confirms no raw data access | `true` |
| `no_raw_data_access` | Governance boundary maintained | `true` |
| `no_decision_making` | Cannot make audit decisions | `true` |
| `requires_human_confirmation` | All outputs need human review | `true` |
| `disclaimer_included` | AI disclaimer present | `true` |
| `audit_chain_integrated` | Linked to audit evidence chain | `true` |
| `snapshot_immutable` | Cannot be modified | `true` |

## SOX Compliance

AnalysisReasoningNode implements SOX-required AI oversight:

- **Human Confirmation Required**: All AI outputs must be reviewed by qualified auditors
- **Audit Trail**: Full provenance tracking of AI generation process
- **Decision Authority**: Explicitly marked as "explanation_only"
- **Governance Boundary**: Strict input validation prevents AI from accessing sensitive data
